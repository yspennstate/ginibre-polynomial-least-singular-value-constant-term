# The least singular value of polynomials in Ginibre matrices at the constant term

Yitzchak Shmalo

Let P be a nonconstant polynomial in k noncommuting variables and let X_1, ..., X_k be independent N x N complex Ginibre matrices. We prove that the least singular value of P(X) - P(0) I_N satisfies P{s_min <= t} <= C(N^kappa t^b + e^(-cN)) for all t > 0 and all large N, with constants depending only on P. Han proved this bound at every z != P(0) and asked whether it holds at z = P(0); Collins, Kitagawa, Miyagawa, Yuan and Zhong answered this when P is not constant on C^k. The polynomials left open are those that are constant on C^k; in degree two they are covered by a theorem of Cook, Guionnet and Husson, and an example of degree three is x_1^2 x_2 - x_2 x_1^2. For these polynomials we use a tuple of d x d matrices, d = deg P, at which P - P(0) is invertible. Sizes N = M + s with d | M and d <= s <= 2d - 1 are treated by bounding the determinant of a Schur complement of bounded size with the Carbery-Wright inequality.
